Code, results and explanation in one document

What is a Jupyter notebook?

An open-source web application that lets you create and share documents containing:

Live codeRun it, change it, run it again
EquationsWritten in LaTeX, rendered beautifully
VisualizationsCharts appear right below the code
Narrative textExplain what you did and why

The name comes from three of its original languages: Julia, Python and R. Today kernels exist for dozens of languages.

The course environment

A complete big data platform on your laptop

A playground, not a production cluster

What it is

  • A playground for our labs and assignments
  • Built with the big data technologies companies use in real projects
  • Safe to break: you can always rebuild it

What it isn't

  • An educational environment, unable to cope with true big data workloads
  • A single machine, not a cluster
Good news: moving from the course environment to an enterprise-class platform should be straightforward. The concepts, APIs and tools are the same.

All these technologies are bundled together in a virtual machine (VM) image, so you can run them on your own laptop.

You work from your browser: the tools' web interfaces are reachable at localhost.

OSBDET

OSBDET stands for Open Source Big Data* Educational Toolkit. It consolidates many of the big data frameworks we teach at IE.

It's an open project on GitHub: github.com/raulmarinperez/osbdet

  • It comes with no guarantees :)
  • You are more than welcome to contribute
  • It evolves over time to include more good stuff

Runs on your laptop's chip

The 2026 release builds for amd64 (Intel and AMD laptops) and arm64 (e.g. Apple Silicon Macs).

* Big data in its purest, open-source form. Cloud and software vendors' offerings make adoption easier, but the underlying technologies are the same.
